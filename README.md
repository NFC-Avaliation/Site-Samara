# Protótipo — Samara F. Krevei

Página institucional demonstrativa para apresentar o método Microdreme.

## Prévia direta

Abra `visualizar.html` para ver o protótipo com imagens, estilos e animações reunidos em um único arquivo.

## Projeto local

Para trabalhar na estrutura do projeto, mantenha `index.html`, `styles.css`, `script.js` e a pasta `assets` juntos. Também é possível executar um servidor estático na pasta, por exemplo:

```bash
python -m http.server 4173
```

Depois acesse `http://localhost:4173`.

## Publicação no Render

Este protótipo é estático e não precisa de banco de dados. Ao conectar o repositório ao Render, use a opção **Static Site**, deixe o comando de build vazio e publique a pasta raiz do repositório.

## Mídias e contatos

- As fotos da esteticista, os registros de antes e depois e os prints de WhatsApp enviados pela profissional já estão na página.
- O Instagram aponta para o perfil oficial informado. O botão do WhatsApp abre uma conversa com a mensagem inicial preparada.
