# Protótipo — Samara F. Krevei

Página institucional demonstrativa para apresentar o método Microdreme.

## Prévia local

Abra `index.html` no navegador ou execute um servidor estático na pasta do projeto, por exemplo:

```bash
python -m http.server 4173
```

Depois acesse `http://localhost:4173`.

## Publicação no Render

Este protótipo é estático e não precisa de banco de dados. Ao conectar o repositório ao Render, use a opção **Static Site**, deixe o comando de build vazio e publique a pasta raiz do repositório.

## Conteúdo provisório

- A foto da esteticista e a imagem de comparação são ilustrativas.
- Os depoimentos são exemplos fictícios e precisam ser substituídos por relatos reais autorizados.
- Os botões de Instagram e WhatsApp estão preparados como placeholders. Adicione os links oficiais em `index.html` e remova o aviso correspondente em `script.js` quando os receber.
- O site usa a fonte Lora e declara Austin para títulos. A versão licenciada de Austin poderá ser incluída quando o arquivo da fonte estiver disponível; até lá, o navegador usará uma alternativa serifada.
